# Construindo meu primeiro site com Bootstrap

Landing page de uma empresa fictícia de soluções digitais (**Global Labs**), criada para praticar HTML, CSS e o framework [Bootstrap 5](https://getbootstrap.com/).

🔗 **Acesse a página:** https://malvesgouveia.github.io/construindo-paginas-bootstrap/

![Prévia da página](docs/preview.png)

## Seções

- **Navbar** fixa no topo, com menu responsivo (hambúrguer no celular)
- **Quem somos**: apresentação da equipe
- **Parceiros**: logos dos parceiros
- **Serviços**: cards de Aplicativos, Sites, UX/UI Design e Marketing Digital
- **Contato**: dados de contato e formulário com validação (apenas demonstração, nada é enviado)
- **Rodapé** com o ano atualizado automaticamente

## Tecnologias

- HTML5
- CSS3
- Bootstrap 5.0.2 (CSS e JS bundle, incluídos localmente na pasta `bootstrap/`)
- JavaScript puro (`js/main.js`)

## Como executar

Não precisa instalar nada. Basta clonar o repositório e abrir o `index.html` no navegador:

```bash
git clone https://github.com/malvesgouveia/construindo-paginas-bootstrap.git
cd construindo-paginas-bootstrap
# abra o arquivo index.html no navegador
```

## Estrutura

```
├── index.html
├── css/style.css
├── js/main.js
├── img/          # imagens e logos
├── bootstrap/    # Bootstrap 5.0.2 (somente os arquivos usados)
└── docs/         # imagem de prévia do README
```

## Sobre o conteúdo

Este é um **projeto de estudo**. A Global Labs é uma empresa fictícia, e os textos, contatos (e-mail, telefone e endereço) e os parceiros CodeNova e CloudBase foram criados apenas como exemplo. O logo da Digital Innovation One pertence à própria DIO e aparece aqui como referência ao curso.
